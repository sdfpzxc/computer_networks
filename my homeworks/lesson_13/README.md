# DNS: иерархия имен, зоны и процесс разрешения

## Задание для дз:
Нужно повторить все действия нат из презы циско.

## Чему научились на уроке:
На уроке изучили систему доменных имен (DNS): её иерархическую структуру, понятие зон и процесс разрешения имен. На практике закрепили навыки настройки сетевого оборудования в симуляторе Cisco: научились конфигурировать коммутаторы (создание VLAN, настройка портов доступа и транка), настраивать маршрутизаторы (интерфейсы, IP-адреса, NAT) и проверять связность сети с помощью утилиты ping.
