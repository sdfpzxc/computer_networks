# Практика по подсетям: VLSM и проверка конфигурации

## Задание для дз:
Задание находится в hw7.

## Чему научились на уроке:
На уроке изучили принципы расчета подсетей и планирования адресного пространства. На практике научились определять необходимую длину маски подсети (CIDR) исходя из требуемого количества подсетей и хостов, вычислять количество доступных адресов и хостов с помощью степеней двойки, а также рассчитывать диапазоны IP-адресов, адреса сети и широковещательные адреса для каждой подсети.
