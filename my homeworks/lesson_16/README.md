# Урок. Порты, сетевые сокеты и состояние соединений

## Задание для дз:
Вам потребуется прислать 3 скриншот из wireshark где на 2-х tcp с разными флагами, а на 3 udp

## Чему научились на уроке:

На уроке изучили понятия портов и сетевых сокетов, а также механизмы установления и завершения соединений. Разобрали состояния TCP-соединений и назначение управляющих флагов (SYN, ACK, FIN и др.). На практике освоили работу с анализатором трафика Wireshark: научились фильтровать пакеты по протоколам, находить TCP-сегменты с различными флагами для анализа этапов соединения, а также выделять UDP-датаграммы.
