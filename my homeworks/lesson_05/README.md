# IPv4-адрес: сеть, узел, маска и специальные диапазоны.

## Задание для дз:
 Вам потребуется скачать Cisco и прислать открытую работающую программу, а также выполнить расчеты масок и распределение IP-адресов для подсетей.

## Чему научились на уроке:
На уроке изучили структуру IPv4-адреса (сеть, узел), принципы работы с масками подсети и специальные диапазоны адресов. На практике освоили базовую работу в программе Cisco, научились рассчитывать количество подсетей и узлов с помощью степеней двойки, определять длину маски (CIDR) и проектировать схемы адресации для нескольких зданий с учетом требуемого количества устройств.
