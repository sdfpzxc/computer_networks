# Коммутация Ethernet

## Задание для дз:
Вам потребуется скачать WireShark, запустить отслежевание ethernet пакетов и прислать скрин через репозиторий

## Чему научились на уроке:
На уроке изучили принципы работы технологии Ethernet на канальном уровне модели OSI: разобрали структуру Ethernet-кадра, MAC-адресацию, методы доступа к среде передачи данных (CSMA/CD) и принципы коммутации. На практике освоили базовую работу с анализатором трафика Wireshark: научились выбирать сетевые интерфейсы для захвата, запускать процесс отслеживания пакетов и фильтровать трафик.
