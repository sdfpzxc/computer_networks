# Маршрутизация: таблица маршрутов, gateway и выбор пути

## Задание для дз:
Построить все схемы в циско из презентации.

## Чему научились на уроке:
На уроке изучили принципы маршрутизации: как формируется таблица маршрутов, что такое шлюз по умолчанию (gateway) и по какому принципу маршрутизатор выбирает оптимальный путь для передачи пакетов между разными сетями. На практике научились строить комплексные топологии в симуляторе Cisco, соединять компьютеры, коммутаторы и маршрутизаторы, а также настраивать их для обеспечения связности сети.
