# Cisco

## Задание для дз:
Вам нужно скачать циско и сделать блок через брандмаузер, сюда прислать скрин с блокировкой циско в брендмауэре

## Чему научились на уроке:
На уроке изучили принципы работы сетевых экранов (брандмауэров) и методы фильтрации трафика. На практике научились настраивать правила блокировки для конкретных приложений в операционной системе, а также проверять работоспособность этих правил на примере программы Cisco.
