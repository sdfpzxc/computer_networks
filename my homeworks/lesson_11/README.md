# Nat и Pat: выход частной сети во внешнюю

## Задание для дз:
Вам нужно построить 3 картинку сети в презентации маршрут циско по архитектуре rip

## Чему научились на уроке:
На уроке изучили принципы работы технологий трансляции сетевых адресов NAT и PAT, а также разобрали, как частные сети взаимодействуют с внешними (публичными) сетями. На практике освоили построение сетевой топологии в симуляторе Cisco, настройку протокола динамической маршрутизации RIP и конфигурирование NAT/PAT на маршрутизаторах для обеспечения доступа внутренних устройств во внешнюю сеть.
