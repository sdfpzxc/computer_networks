# Здесь находится практика с уроков

Практическая отработка навыков построения и настройки сетей в симуляторе Cisco Packet Tracer.

## Чему научились на уроках:

На уроке изучили принципы построения локальных сетей и научились собирать комплексные топологии в симуляторе Cisco. На практике освоили соединение маршрутизаторов и хабов для передачи данных между разными сегментами сети (Схема 1), а также построение клиент-серверной архитектуры с использованием коммутаторов, серверов и ПК (Схема 2). Научились проверять работоспособность сети в режиме симуляции и анализировать прохождение пакетов.
